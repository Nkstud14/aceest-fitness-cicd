📞 GETTING STARTED WITH THE SUBMISSION
═══════════════════════════════════════════════════════════════════════════════

1. Clone the Repository:
   git clone https://github.com/Nkstud14/aceest-fitness-cicd.git
   cd aceest-fitness-cicd

2. Review Documentation:
   cat 00_START_HERE.md        # Quick overview
   cat DEVOPS_REPORT.md        # Full report (submission requirement)

3. Local Development:
   python -m venv .venv
   source .venv/bin/activate   # Windows: .venv\Scripts\activate
   pip install -r requirements.txt -r requirements-dev.txt
   pytest                       # Run tests
   python wsgi.py              # Start app

4. Docker Deployment:
   docker build -t aceest-fitness:latest .
   docker run -p 5000:5000 aceest-fitness:latest

5. Kubernetes Deployment:
   minikube start
   kubectl apply -f k8s/

6. Jenkins Integration:
   • Create new Pipeline job pointing to repository
   • Use Jenkinsfile from repository root
   • Add Docker Hub credentials
   • Add SonarQube credentials
   • Add Kubernetes credentials
